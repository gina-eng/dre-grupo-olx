# DR-E — Grupo OLX

Repositório central de informações do projeto **DR-E (Destrava Receita Estratégico)** para o cliente **Grupo OLX**.

## Objetivo

Centralizar em um único lugar tudo que orbita o projeto: playbook da metodologia, contexto do cliente,
diagnóstico, estratégia, execução, resultados e histórico de reuniões.

## Estrutura

| Pasta | O que guarda |
|---|---|
| [00-playbook/](00-playbook/) | Playbook do DR-E: metodologia, etapas, entregáveis e critérios de qualidade |
| [01-cliente/](01-cliente/) | Contexto do Grupo OLX: negócio, unidades, produtos, ICP, stakeholders, acessos |
| [02-diagnostico/](02-diagnostico/) | Levantamento e análise da situação atual: dados, auditorias, gargalos |
| [03-estrategia/](03-estrategia/) | Hipóteses, teses de crescimento, plano estratégico e roadmap |
| [04-execucao/](04-execucao/) | Planos de ação, sprints, backlog, responsáveis e prazos |
| [05-resultados/](05-resultados/) | KPIs, acompanhamento de metas, relatórios e dashboards |
| [06-reunioes/](06-reunioes/) | Atas, transcrições e decisões de calls e workshops |
| [assets/](assets/) | Arquivos de origem: PDFs, planilhas, apresentações, exports |

## Convenções

- Documentos em **Markdown**, nomeados em `kebab-case` com data quando fizer sentido: `2026-08-23-kickoff.md`.
- Arquivos originais (PDF, XLSX, PPTX) vão em `assets/originais/`; o conteúdo relevante é transcrito em Markdown na pasta temática.
- Nada de credencial no repositório — o repo é privado, mas segredos ficam fora dele.
