# 05 · Resultados

Acompanhamento de métricas e evidência de evolução do sistema.

## O indicador-mãe

**Throughput** = Vendas − Custos Totalmente Variáveis (margem de contribuição).
Não é faturamento bruto. Não é lucro líquido.

Métricas intermediárias (leads, CTR, sessões) são **sintomas que apontam para a restrição**,
nunca fins em si mesmas.

## A produzir nesta pasta

- [ ] `baseline.md`: estado do sistema no início do Ciclo 1 (a foto que torna a evolução demonstrável)
- [ ] `acompanhamento-metricas.md`: leitura recorrente, com foco na etapa da restrição
- [ ] `evolucao-ciclo-1.md`: antes/depois, com classificação de desvios
- [ ] `evidencias-success-fee.md`: comprovação técnica para o bônus do 12º mês

## Classificação obrigatória de desvios

| Categoria | Significado |
|---|---|
| **Erro de execução** | Plano correto, execução falha |
| **Erro de hipótese** | Premissa do diagnóstico ou do forecast incorreta |
| **Limite estrutural** | Sistema atingiu capacidade máxima |

Essa classificação direciona a decisão do Comitê 2 (otimizar mais vs. expandir).
